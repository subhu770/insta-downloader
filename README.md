# 📸 Insta Downloader

An ultra-fast, responsive, modern, and completely ad-free web application to download Instagram Reels, Photos, and Carousel posts in high quality.

Made with ❤️ in India 🇮🇳

## ✨ Features
- 🎬 **Instagram Reels Downloader:** Fetch and download high-definition `.mp4` video reels instantly.
- 📸 **Photos & Carousels:** Download single photos, multi-slide carousels, and high-res post images.
- ⚡ **Lightning Fast:** Clean proxy extraction with zero delay.
- 📱 **Fully Responsive UI:** Built with Tailwind CSS and dark mode aesthetic.
- 🛡️ **Privacy Focused & Ad-Free:** No tracking, no annoying ads.

## 🛠️ Tech Stack
- **Backend:** Python (Flask), Gunicorn
- **Frontend:** HTML5, Tailwind CSS, JavaScript, Lucide Icons
- **Hosting Ready:** Prepared for Vercel (Frontend) & Render (Backend)

## 🚀 Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/subhu770/insta-downloader.git
   cd insta-downloader
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open `http://localhost:5000` in your browser.
